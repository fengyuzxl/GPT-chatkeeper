批量删除 · 文件夹 · 搜索 · 提示词

如何打开面板

  1. 先登录 chatgpt.com。
  2. 点击页面右下角的绿色悬浮按钮，或按 Alt + Shift + M。
  3. 也可以在浏览器工具栏点击 ChatKeeper 图标，再点「打开面板」。
  4. 安装或更新扩展后，需要刷新 ChatGPT 页面。

批量删除

  1. 打开面板，扩展会用当前登录会话拉取全部对话。
  2. 用搜索、时间筛选或左侧文件夹定位。
  3. 勾选对话，或用表头「全选」。
  4. 点「删除」→ 确认 → 等待进度完成。

删除调用 ChatGPT 网页端同一接口，效果等同于在侧边栏逐个删除。

文件夹与子文件夹

  • 新建文件夹后，可在文件夹菜单里继续新建子文件夹，或用拖拽把文件夹放进另一个文件夹。
  • 勾选对话后点「移动到文件夹」，或直接把对话行拖到文件夹上。
  • 文件夹可上移或下移排序；删除父文件夹时，子文件夹会提升到上一级，对话回到「未分类」。
  • 父文件夹的计数包含所有子文件夹，点击父文件夹会显示其下全部对话。
  • 文件夹与归类只保存在浏览器本地，不会上传到任何服务器。

智能选择与删除快照

  • 按「超过 N 天未更新」「标题包含或不包含」等条件一次选中对话，支持追加或替换当前选择。
  • 删除前会在本地保存快照，记录标题、时间与所属文件夹。
  • 快照可在「删除快照」中查看或导出 JSON；它只用于事后核对，无法恢复 ChatGPT 对话。

正文搜索

  • 在搜索框输入关键词，点「正文搜索」，扩展会逐条读取对话内容。
  • 搜索有进度、可随时停止；结果会显示命中片段并高亮。
  • ChatGPT 没有可用的服务端全文搜索，因此这是个慢功能，且会消耗网络请求。建议先用文件夹或时间缩小范围。
  • 正文索引只存在内存中，刷新页面后需要重新读取。

提示词库与优化

  • 在左侧打开「提示词库」，可以创建、编辑、搜索提示词模板；用 {{变量}} 占位，使用时一键填入输入框。
  • 对模板或当前输入框点「优化」，可用 GLM-4-Flash 改写提示词；结果不会自动发送。
  • 输入框旁还有一个一键优化按钮：点击后直接替换提示词，并可在提示条中撤销。
  • 在设置 →「AI 提示词优化」中填入 open.bigmodel.cn 的免费 API Key；未配置时使用本地结构化优化。
  • 可在设置里选择优化风格，或关闭输入框旁的优化按钮。
  • API Key 只保存在本浏览器，不写入导出；优化时只会把当前提示词发送到智谱，不发送对话历史。

原生侧边栏增强

  • 在 ChatGPT 自带的对话列表左侧显示文件夹色条；鼠标悬停会出现复选框。
  • 底部的批量操作栏可移动、归档、删除；右键对话可打开快捷菜单。
  • 如果 ChatGPT 改版导致显示异常，可在设置中关闭原生增强，面板功能不受影响。

界面语言与数据

  • 界面支持中文与英文，默认跟随浏览器语言，可在设置中切换。
  • 文件夹、归类、设置保存在浏览器本地；可导出 JSON 备份，也可导入合并或替换。
  • 清理列表缓存不会影响文件夹与归类数据。

使用前请注意

  • 批量删除不可撤销，请先小批量验证。
  • 这是第三方扩展，与 OpenAI 官方无关。
  • 请只操作自己的账号。
  • 扩展仅申请 storage、ChatGPT 站点访问权限，以及可选的 open.bigmodel.cn 权限，不加载远程代码。
  • AI 优化需要你自己的 API Key，并会把当前提示词发送到智谱；不点击优化则不会联网。
  • ChatGPT 接口可能随时调整；如果失败，请查看设置中的接口诊断与失败提示。
